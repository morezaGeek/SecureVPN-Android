## What’s new in SecureVPN 1.1.9

- Check for updates from GitHub in Settings. View release notes, download the APK for your device, and open Android’s installer after verification.
- SecureVPN checks about once a day and can notify you about new versions. Downloads only start on request and can be canceled.
- Profile cards have square corners and monospace text. Long-press a profile to reveal Edit, Share, and Delete.
- Ping moves to the top right and is color coded: blue below 100 ms, green through 160 ms, yellow through 270 ms, and red above 270 ms. XHTTP mode details remain in settings.
- Keeps the CPU awake while the VPN is connected to help reduce disconnects with the screen off. This can increase battery use.

Choose one APK for your device. For most modern phones, use arm64-v8a. Each APK is a standalone installer signed with the existing GitHub release key.
